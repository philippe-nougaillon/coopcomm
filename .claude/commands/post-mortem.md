Lis le **template T10 — « Post-mortem d'incident »** dans `.claude/method/kit-prompting.md` (dans `.claude/method/` — sinon `~/aikku/CLAUDE/kit-prompting.md`). Applique-le rigoureusement aux faits suivants (timeline brute / logs / messages — « mode bourré » accepté, ne te censure pas) : $ARGUMENTS

Rappels :
- **Blameless** — pas de recherche de coupable.
- **Distinction stricte fait / déduction** (« le texte ne précise pas… »).
- Liste aussi ce qui a **bien marché** (détection, mitigation, communication).
- Pour chaque action : owner suggéré, type (préventif/détectif/réducteur d'impact), critère de « fait ».
- Devil's advocate : quelle action de la liste risque de créer un nouveau problème ?
- Style : concret brutal, pas de « il est crucial de noter que », pas d'hyperboles, pas de tirets quadratins.
